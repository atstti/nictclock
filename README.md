# NICT Analog Clock

Python 3.11以上とPySide6で動作するmacOS / Windows 10・11向けアナログ時計です。NICTの公式アプリではありません。OSの時計は変更しません。

## macOSでインストール・起動

Python 3.11以上をインストールし、ターミナルでこのフォルダーに移動してください。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Windowsでインストール・起動

Python 3.11以上（64bit推奨）をインストールし、PowerShellでこのフォルダーに移動します。仮想環境の有効化は不要です。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

`py -3 --version` で3.11以上であることを確認してください。

## 操作

- 時計をドラッグして移動。標準ウィンドウの端、または右下のサイズグリップでリサイズできます。
- 右クリックで同期、設定、最前面切替、最小化、終了を選択できます。
- 設定画面の「適用」で、デザイン、秒針、スイープ/ステップ、デジタル表示、ミリ秒、透過、枠なし、最前面、タイムゾーンなどが反映されます。
- サイズの初期値はウィンドウ全体で320×320論理pxです。下部の表示領域を除いた範囲で時計盤を正円に保ちます。情報量やOSの文字サイズによって最小サイズは拡大します。
- 枠なしでも右下のグリップと右クリックメニューを利用できます。透過度は20〜100%。背景透過を有効にするとOS互換性のため枠なしになり、時計盤の塗りとウィンドウ背景を透過し、文字・目盛り・針は残します。
- Minimalは数字を省略します。Classic / Darkは1〜12と60目盛りを表示します。
- タイムゾーンには `Asia/Tokyo`、`UTC`、`America/New_York` などIANA名を指定してください。JST以外では現地の略称を表示します。Windowsにもtzdataを同梱します。
- ログイン時の自動起動は設定から明示的に有効化します。macOSはユーザーのLaunchAgents、WindowsはユーザーのRunレジストリに登録します。次のログインから有効です。有効化後にアプリやPython環境を移動した場合は一度OFFにしてからONにしてください。アンインストール前にもOFFにします。

## 時刻同期の仕様

起動時と通常15分間隔で `ntp.nict.jp:123/UDP` に問い合わせます。外部通信はNTPと、その接続先を調べるOSのDNS処理のみです。広告・テレメトリ・更新通信はありません。依存関係のインストールやGitHub Actionsは別途ネットワークを使用します。

RFC 5905のクライアント要求（version 4 / mode 3）を送り、サーバー応答（version 3/4 / mode 4）を検証します。接続済みUDPで相手を限定し、階層、leap状態、要求のoriginate timestamp一致、受信/送信時刻、遅延を検証します。2036年のNTP era境界もクライアント時刻を基準に展開します。

```
offset = ((T2 - T1) + (T3 - T4)) / 2
RTT = (T4 - T1) - (T3 - T2)
```

送信時のシステム時刻T1と単調増加クロックを保存し、受信時T4を単調増加クロックの経過から算出します。同期後は「補正済みUTC + monotonic_ns経過」で表示を駆動します。システム時刻が途中で変わっても表示時刻に直結しません。次の同期では新しい基準へ即座に補正するため、補正量が大きければ表示が動くことがあります。これは補正を徐々に適用する方式ではありません。

通信とDNSはバックグラウンドで行い、DNSを含め原則3秒の待ち上限を設けます。OSのDNS呼び出し自体は中断できませんが、専用デーモンスレッドで隔離し、同時に1件までに制限しています。GUIやアプリ終了を待たせません。

失敗時は60、120、240、480、900秒で再試行します。手動同期も連打防止のため最短60秒です。KoD（アクセス制限応答）を受けた場合は最低15分待ちます。通常の自動同期間隔は60〜86400秒に設定可能ですが、デフォルトの900秒を推奨します。復帰時やアクティブ化時は再同期を予約します。5秒以上の処理間隔またはシステム時刻と単調クロックの差の変化でも復帰候補を検出します。

初回失敗時は起動時のローカル時刻を基準に継続し、「未同期：ローカル時計で暫定動作」を表示します。一度同期した後の失敗は、そのプロセス内の最後の同期を使い続けます。最終同期から通常30分以上（設定同期間隔の2倍がそれ以上ならその値）経過すると精度低下の可能性を表示します。再起動時には新たに同期します。

OSが明確に回線切断を通知した場合は「オフライン」、それ以外のDNS・UDP失敗は「接続エラー」と表示します。回線断とサーバー障害を通信失敗だけから断定しません。ステータスにはサーバー、Offset、RTT、最終同期日時を表示します。OffsetとRTTは測定値であり絶対精度の保証ではありません。ネットワーク経路の非対称性、発振器のドリフト、描画遅延、スリープ時間などで誤差が生じます。認証されたNTP/NTSやフルNTPデーモンの実装ではありません。

## 設定の保存先

JSONを一時ファイルから置き換える方式で保存します。終了時に位置・サイズも保存します。

- macOS: `~/Library/Application Support/NICTAnalogClock/settings.json`
- Windows: `%APPDATA%\NICTAnalogClock\settings.json`

不正な設定ファイルは初期値へ戻します。位置をリセットするにはアプリを終了してJSONを退避してください。モニター取り外しや復元時に画面外のウィンドウを表示範囲へ戻します。

## macOSの.appビルド

**macOS上**で実行します。Windows版はクロスビルドしません。

```sh
bash build_mac.sh
open dist/NICTAnalogClock.app
```

出力は `dist/NICTAnalogClock.app`。使用したPythonのアーキテクチャに従います。Apple SiliconとIntelの両方が必要なら対応するMac環境で別々にビルドして検証してください。配布用のDeveloper ID署名とApple公証は含みません。第三者へ配布する際は適切に署名・公証してください。

## Windowsの.exeビルド

**Windows上**のPowerShellで実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
.\dist\NICTAnalogClock.exe
```

出力は単一ファイルの `dist\NICTAnalogClock.exe`。コンソールウィンドウは表示しません。Authenticode署名は含みません。初回起動時にPyInstallerの展開処理が入ります。

両スクリプトは専用の `.venv-build` を作成し、tzdataを含めてパッケージ化します。`.github/workflows/build.yml` にはmacOS / Windowsのネイティブビルドを手動実行するGitHub Actionsも用意しました。このフォルダーの内容をリポジトリのルートに配置して利用してください。CIはこの納品時点では未実行です。

## トラブルシューティング

- **同期できない**: インターネット接続とDNS、ファイアウォールのUDP送受信123番を確認してください。HTTPプロキシ経由ではNTPを利用できません。企業ネットワークでは管理者が指定するNTPサーバーへ変更してください。
- **同期ボタンが押せない**: 通信中、または前回の要求から60秒未満です。KoDや通信エラー時には自動再試行を待ってください。
- **時刻が大きく違う**: タイムゾーンを確認してください。OSの日付が数十年以上ずれている場合はera推定にも影響するため、OSの日付も確認してください。
- **透過・最前面が効かない**: OSのウィンドウ管理によって挙動が異なります。枠なしと背景透過を組み合わせてください。全画面アプリより前面に出ることは保証しません。各OSの実機で確認してください。
- **見失った**: 設定JSONを退避して起動し直してください。
- **起動できない**: Pythonのバージョン、PySide6のインストール先、同一の仮想環境を使っているか確認してください。ソース版をターミナルから起動するとエラーを確認できます。
- **macOSのセキュリティ表示**: 自分で作成した未署名ビルドであることを確認し、システム設定のプライバシーとセキュリティからOSの手順に従ってください。
